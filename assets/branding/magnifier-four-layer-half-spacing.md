# Half-spacing magnifier variant

This [editable SVG](magnifier-four-layer-half-spacing.svg) is an alternative to [the original four-layer master](magnifier-four-layer.svg). It retains the same exact traced geometry, lens pivot, colour fills, stacking order, and editable SVG `<use>` instances.

All rotation and diagonal offset magnitudes are **halved** from the original: each step adds **9.5° clockwise** rotation about the base lens pivot (546.102, 466.631) and **69.12 SVG units (4.5% of the original 1536-unit canvas)** of horizontal and vertical translation.

| Layer | Rotation from white | X and Y offset |
|---|---:|---:|
| White | 0° | 0 |
| Red | 9.5° | 69.12 |
| Blue | 19° | 138.24 |
| Yellow | 28.5° | 207.36 |

The original artwork remains intact; this alternate layout is a standalone branding exploration and does not modify either application's deployed icon or UI.
