## Derive the rule, then deliberately break it

A case contributes a **conditional** rule only after capturing positive example, negative counterexample and the decisive cue. For example, “prefer exclusive creation” is appropriate for preserving app-private originals but not a universal ban on user-authorized torrent payload reuse. Transfer the invariant to another domain (database row, cloud document, remote operation) before promoting it into generic instructions.

A compelling case is not a prevalence estimate. Historical green tests on obsolete branches, user-reported problems without repro and design contracts without shipped behavior must be labeled separately.
