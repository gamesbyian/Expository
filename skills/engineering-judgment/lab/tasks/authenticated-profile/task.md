# Task: authenticated remote profile

A remote controller saves account profiles when a user presses **Connect**. Its version endpoint is public and succeeds even when the submitted credentials are wrong. Change `candidate.py` so Connect succeeds only after **the supplied exact account credentials have been genuinely authenticated** against the protected operation. An unsuccessful attempt must neither create an authenticated profile nor destroy an existing verified profile. The endpoint exposes `version()` and `authenticate(username,password)`, the latter returns the authenticated principal or raises PermissionError/ConnectionError/TimeoutError. Preserve the existing `connect(profiles, endpoint, profile_id, username, password)` interface and boolean result. Do not change other files.
