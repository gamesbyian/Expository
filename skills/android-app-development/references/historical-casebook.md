# Historical casebook: inspected source-linked failure and success examples

**Source class:** linked GitHub issue or PR description, plus project agent/audit/evidence documents inspected in the 2026-10-31/11-01 snapshot. This is a curated *deeper selection* after a full PR metadata enumeration; it is not a complete manual diff/review/Actions audit. Each outcome is scoped to the cited artifact/date. Check current live source before reusing the claim.
