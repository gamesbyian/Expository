# Project lessons: what these repositories uniquely demonstrate

Each item links to an existing owner-controlled artifact. These are historical evidence for process, not a claim that all generated models are correct, current or shipped.

## Chunks: the map discovery/falsification loop is already real

[240-feature inventory](https://github.com/gamesbyian/Chunks/blob/main/docs/BITTORRENT-ECOSYSTEM-FEATURE-INVENTORY-2026-10-29.md) and [240 activities / 36 journeys](https://github.com/gamesbyian/Chunks/blob/main/docs/BITTORRENT-USER-GOALS-AND-WORKFLOWS-2026-10-29.md) were researched separately and intentionally classified as **non-normative**. [Multilingual aversion/praise and abandonment research](https://github.com/gamesbyian/Chunks/blob/main/docs/BITTORRENT-USER-AVERSION-RESEARCH-2026-10-29.md) separates independent first-person testimony from contextual inference and misleading prevalence claims.

The [typed concept graph](https://github.com/gamesbyian/Chunks/blob/main/docs/research/BITTORRENT-CONCEPT-GRAPH-2026-10-29.json) reported **943 nodes, 4,118 edges, 72 candidate hypotheses, 55 friction factors** and typed cross-links among goals, features, activities and outcomes. A [disconfirmation audit](https://github.com/gamesbyian/Chunks/blob/main/docs/research/BITTORRENT-CONCEPT-MAP-EVIDENCE-AUDIT-2026-10-29.md) found existing features in qui, cross-seed and others that refuted broad novelty claims. The [synthesis](https://github.com/gamesbyian/Chunks/blob/main/docs/research/BITTORRENT-MISSING-FEATURES-SYNTHESIS-2026-10-29.md) consolidated 72 hypotheses into **33 distinct capability families**, with **7 not explicitly integrated in the sampled feature inventory**, **8 partially documented elsewhere**, **16 containing known primitives**, **2 platform bounded**. This is a bounded map-coverage statement, not evidence of seven market-first ideas. **Teaching lesson:** build big enough to cross-connect, then *shrink* unqualified discoveries after aggressive retrieval and deduplication.

## AYA: product understanding and truth separation

[Application Understanding Framework](https://github.com/gamesbyian/AYA/blob/main/docs/understanding/README.md), [model-building passes](https://github.com/gamesbyian/AYA/blob/main/docs/understanding/MODEL.md), [adaptive questions](https://github.com/gamesbyian/AYA/blob/main/docs/understanding/QUESTIONS.md), and [director consultation](https://github.com/gamesbyian/AYA/blob/main/docs/understanding/CONSULTATION.md) already require product thesis, ontology, goal-to-capability model, design tensions, mental-model conflicts, actual shipping trace and separate `intention/implemented/observed/expectation`. The normative [packet authoring](https://github.com/gamesbyian/AYA/blob/main/docs/packet/AUTHORING_STANDARD.md) compiles model-backed claims with actual app/version identity. **Teaching lesson:** a model must inform a downstream artifact and prove referential integrity, without creating fictitious approvals. Reuse rather than duplicate these schemas for AYA-specific work.

## Glimpse: superficial coverage is cheap, genuine usability coverage is hard

The [visual-reference gap audit](https://github.com/gamesbyian/Glimpse/blob/main/docs/design/reference-gap-audit.md) reported **73/73 workflows routed, 24/24 draft screen-family plates and 127/127 required elements text-traced**, while explicitly rejecting "100% visually complete": text annotations were not actual accessible controls rendered in a phone viewport; 63 variant states and owner approval remained separate. The [reel UX audit](https://github.com/gamesbyian/Glimpse/blob/main/docs/design/reel-ux-audit.md) uses a typed reel model (traversed set, selected identity, order, consequence, apply boundary, count/endpoints, feedback and accessibility) to rule out decorative faux controls. **Teaching lesson:** maps must be checked against real reachable artifacts and counterfactual user actions, not just total row-to-row linkage.

## Expository: model operation invariants before UI implementation

The [Android operation-state UX model](https://github.com/gamesbyian/Expository/blob/main/docs/android-transfer/OPERATION-STATE-UX.md) distinguishes proposing, approval, attempt recorded, writing, verifying, verified, partial and uncertain, and says Single, Dual, drag and keyboard must converge on the **same command digest**. The [architecture audit](https://github.com/gamesbyian/Expository/blob/main/docs/android-transfer/ARCHITECTURE-AUDIT-2026-10-29.md) checks those invariants against real Compose and adapter source. **Teaching lesson:** a graph of feature boxes can conceal essential state transitions and authority. A real shared-operation model finds design holes before coding.

## UR-Recomp: frontier discovery is not acceptance

[Semantic sufficiency](https://github.com/gamesbyian/UR-Recomp/blob/main/docs/SEMANTIC-SUFFICIENCY.md) judges **observe/explain/modify/validate** for each subsystem with explicitly scoped sufficiency. The [adaptive research frontier](https://github.com/gamesbyian/UR-Recomp/blob/main/docs/QA-ADAPTIVE-RESEARCH-FRONTIER.md) and [10,000-case postmortem](https://github.com/gamesbyian/UR-Recomp/blob/main/docs/QA-FRONTIER-10000-POSTMORTEM-20261013.md) report **20,179 exact normalized field fingerprints** across two cohorts but **zero** original/native complete event-family acceptance. A strategy sampler could starve an unexplored input class even in a large campaign. The [3D inverse-graphics spec](https://github.com/gamesbyian/UR-Recomp/blob/main/docs/HD-RACER-INVERSE-GRAPHICS-SPEC.md) separates original pixels, camera/pose hypotheses and underdetermined inferred geometry. **Teaching lesson:** a huge "new state" count may be a measurement artifact or already-understood projection; unexplored strategy classes are sampling gaps, not new validated game behavior. Holdout ground truth and interventions are necessary.

## Shared principle

The best frontier is a **cross-boundary seam** where the model can represent the inputs, constraints and outcomes clearly but cannot yet account for an important transition. It earns priority only when independent evidence, ontology repair, counterexample search and actual outcome tests fail to explain it away.
