Extract ZIP to GitHub

This is a separate, opt-in publishing tool. It cannot change a repository until you explicitly review and confirm. Your write-capable token stays in this tab's memory.

Incoming files

Waiting for a one-time handoff from the Expository ZIP viewer. Open an archive there and choose “Publish to GitHub”.

Destination

Never paste a token into the normal Expository viewer to enable publishing. This writer does not remember credentials. The output always goes to a newly created branch, never directly to your base branch.

Permissions and safeguards

Maximum 100 files, 32 MB uncompressed, 16 MB per file. ZIP decoding and checksums are completed in Expository before this handoff. The writer checks repository-tree completeness, existing destination paths and base-branch identity, then creates Git objects and a new branch. Existing GitHub files are never overwritten. A failed or cancelled upload may leave unreachable Git objects, but cannot update the base branch.
