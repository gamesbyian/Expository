## Release-audit overlap and web separation

See the [45-concern release-blocker crosswalk](android-transfer/RELEASE-BLOCKER-CONSOLIDATION-2026-11-03.md). Native concerns 1–35 are grouped into seven shared delivery workstreams rather than new issue-by-issue implementation lanes. Web concerns 36–45 stay under E03–E12: repo security/large-tree resilience (E03), preview limits (E04), history/date accuracy (E06/E11), mobile accessibility/visual review (E05/E07/E10), Pages/PWA boundaries (E08), and ZIP/publisher verification (E12). Reuse safe fixture/browser sessions but preserve private-session and writer isolation, and do not make finite documented feature limits global release blockers without a corresponding release promise.
