## Current truthful baseline

Implemented developer-preview foundations: default Single and optional independently navigable Dual; Android scoped local and document-provider browse/pickers; limited confirmed SAF file and synthetic recursive Copy with nested/empty-folder readback; guarded SFTP upload/download/two-session relay; trusted FTPS browse/Save As; opt-in **read-only** insecure FTP browse; anonymous read-only public GitHub browse plus bounded original-file Save As. Immutable Kotlin planner, journaled copy/rename **planning**, destination conflict guards, SFTP connection-only encrypted bookmarks and synthetic E1/E2/E3 tests exist. Some tests prove actual bytes in synthetic providers and controlled loopback servers; they do not establish cloud, external-device or final UI acceptance.

**Not delivered:** unified feature-complete Single remote workflow; all endpoint/pane combinations; real two-authority OS-picker recursive E2; safe FTPS upload; automatic or approved restart reconciliation queue; remote bulk Rename Apply/undo; verified Google Drive original upload/Docs conversion; biometric/session-gate UI; E4 real third-party provider/physical handset; E5 signed beta. Do not confuse a compiled APK or UI proposal with transported bytes.
